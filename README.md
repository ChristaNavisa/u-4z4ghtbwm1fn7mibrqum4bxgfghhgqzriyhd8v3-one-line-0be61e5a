Entry for the make.fun competition [One Line, One Laugh](https://make.fun/c/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) — a single funny line, written by `main.ts` to `/output/entry.txt`.

The line: "My goldfish sued me for emotional neglect." (42 characters, one line, no trailing newline.)

## Gate

The program refuses to write anything outside 1–140 non-blank characters, so the output always passes the competition gate.

## Run

```sh
node main.ts
cat /output/entry.txt
```
